# Oonjal Chai Management System

A cafe management, fast food POS, and order dispatch system for **Oonjal Chai** (Sri Lanka).

## Tech Stack

- **Frontend**: React 19 + TypeScript + Vite + Tailwind CSS
- **Backend**: Laravel REST API (Part 2)
- **Database**: MySQL (Part 2)
- **Operating Hours**: 4:00 PM – 1:00 AM (Asia/Colombo)
- **Currency**: Sri Lankan Rupees (Rs. / LKR)

## Project Structure

- `/frontend`: React + TypeScript frontend application with POS UI, Dashboard, and live token tracking.
- `/backend`: Laravel API backend (upcoming in Part 2).
